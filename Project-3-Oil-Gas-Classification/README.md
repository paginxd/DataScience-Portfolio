# 🛢️ Классификация мест залежей нефти и газа

Задача представлена на платформе [Kaggle](https://www.kaggle.com/competitions/classification-of-oil-and-gas/overview) в рамках образовательных программ НИЯУ МИФИ.  

**Цель данного проекта** — разработать модель машинного обучения, которая по геологическим и географическим параметрам определяет тип расположения месторождения:  
- 🟢 **ONSHORE** — на суше  
- 🔵 **OFFSHORE** — в море  
- 🟡 **ONSHORE-OFFSHORE** — смешанный тип

---

## 📌 Задачи проекта

- Исследование и анализ данных (EDA)
- Предобработка данных (обработка пропусков, кодирование категориальных признаков, масштабирование)
- Feature Engineering (создание новых признаков)
- Анализ важности признаков
- Обучение и сравнение нескольких моделей классификации
- Подбор гиперпараметров
- Выбор лучшей модели и объяснение выбора
- Формирование предсказаний на тестовых данных
- Экспорт результатов в формате `.csv` для загрузки на Kaggle

---

## 📊 Описание данных

Датасет содержит **442 записи** о нефтегазовых месторождениях (309 — обучающая выборка, 133 — тестовая).  
Каждое месторождение описывается **19 параметрами**:

| Признак | Описание |
|---------|----------|
| `Field name` | Название месторождения |
| `Reservoir unit` | Юнит месторождения |
| `Country` | Страна расположения |
| `Region` | Регион расположения |
| `Basin name` | Название бассейна пород |
| `Tectonic regime` | Тектонический режим |
| `Latitude` | Широта |
| `Longitude` | Долгота |
| `Operator company` | Название компании-оператора |
| **`Onshore/Offshore`** | **Целевая переменная** (ONSHORE — 1, OFFSHORE — 0, ONSHORE-OFFSHORE — 2) |
| `Hydrocarbon type (main)` | Тип углеводорода |
| `Reservoir status (current)` | Статус месторождения |
| `Structural setting` | Структурные свойства |
| `Depth (top reservoir ft TVD)` | Глубина залегания (футы) |
| `Reservoir period` | Литологический период |
| `Lithology (main)` | Литология |
| `Thickness (gross average ft)` | Общая толщина (футы) |
| `Thickness (net pay average ft)` | Эффективная толщина (футы) |
| `Porosity (matrix average)` | Пористость |
| `Permeability (air average mD)` | Проницаемость |

---

## 🧠 Использованные модели

Были обучены и сравнены следующие модели:

- **Logistic Regression**
- **Random Forest**
- **Gradient Boosting**
- **SVM**

Лучший результат показала модель **Random Forest** с подобранными гиперпараметрами.


## Результат

В ходе работы удалось достичь **F1-score = 0.83366** на тестовой выборке Kaggle.
Однако данный результат можно улучшить за счет обработки дисбаланса классов.
